## Demonstrations and scope

The catalog is a live static website with search, filters, screenshots and recorded outputs. Application backends run locally; no inactive backend URLs are presented as public demos. Python 3.12 is the validated common runtime. TabHarbor uses Chrome-compatible browsers and Node.js 22 for testing. Project-specific startup commands are in each README.

- **Real model runs:** Ticket Tuner includes measured local fine-tuning; DocSearch and Release Pilot include local inference evidence; EvalBench retains actual model responses. Downloading base models or retraining Ticket Tuner is required after a clean clone. No paid API key is required.
- **Cloud:** Shipyard ran a real temporary CI container; Scale Lab ran a real disposable kind cluster. Network Foundry passed configuration and mock tests; no paid AWS resources were deployed. Failover Forge is a stateless local two-process experiment.
- **Data:** Synthetic datasets are labeled. Energy Brief reproduces a pinned public OWID subset with source and subset checksums. Model and data licenses remain separate from the project code license.
- **Open source:** Upstream Lab contains a real regression patch and contribution draft. It has not been submitted or accepted upstream.
- **Preservation:** Existing DocSearch, Retention Studio, AWS network and retail work was reused where it matched. Existing GitHub histories were preserved. Unrelated repositories were left intact.

## Local layout

Each application is independent. Clone individual repositories for their own setup, or use the delivered local category folders:

```text
career-portfolio/
  software-engineering/
  data-science-ml/
  ai-ml-engineering/
  cloud-devops/
  data-analytics/
  portfolio-index/
```

The machine-readable [projects.json](projects.json) records implementation, tests, documentation, completion, publication, verification boundaries and local locations separately. It includes the original workspace paths; use your own checkout path on another machine.

## Run this catalog

```sh
python3 -m http.server 8099 --directory docs
```

Open http://127.0.0.1:8099. Static assets are self-contained. No build step, API credentials, analytics trackers or external font dependency is required. GitHub Pages serves the `docs` directory from `main`.
