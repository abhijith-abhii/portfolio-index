HOW TO READ THIS PORTFOLIO

Evidence before claims.

Each repository includes the scope, architecture, startup steps, learning guide, interview questions and measured results. This collection was developed with substantial Codex assistance and is presented as portfolio learning work.

01

Run it yourself

Application demos run locally. This site hosts screenshots and recorded outputs; it does not operate their backends.

02

Know the boundaries

Synthetic data is labeled. Benchmarks describe the measured dataset. Cloud configuration is distinct from a paid deployment.

03

Make it your own

Follow the guide, explain the decisions and complete an independent extension before using a project in interviews.
