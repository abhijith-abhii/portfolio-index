# Why these five Cloud / DevOps projects

The user authorized independent Cloud/DevOps choices after the source carousel contained no Cloud/DevOps slide. These are not claimed as entries in the Instagram post.

The [CNCF 2025 survey](https://www.cncf.io/reports/the-cncf-annual-cloud-native-survey/) reports widespread production use of Kubernetes among surveyed container users. This is an industry adoption signal, not a count of job openings or a guarantee of employability. The selection below is our interpretation of useful, demonstrable infrastructure skills.

| Project | Skill demonstrated | Verification boundary |
|---|---|---|
| Shipyard | Reproducible container delivery, health checks, non-root runtime | Temporary CI deployment; no public production service |
| Network Foundry | Infrastructure as code, private network design, failure diagnostics | Mock-provider tests; no paid AWS deployment |
| CostCompass | Cost allocation, tagging quality, anomaly review | Synthetic billing data; hypothetical savings |
| Failover Forge | Failure injection, recovery timing, honest reliability limits | Two local processes; no data replication |
| Scale Lab | Resource requests, probes, HPA policy and measured scaling | Disposable Kubernetes CI cluster; no paid cluster |
